# 💍 Invitación digital de boda

## 1. Editar datos
Abre `script.js` y modifica únicamente la sección:

`💗 DATOS DE LA BODA — EDITA SOLAMENTE ESTA PARTE`

Ahí puedes cambiar nombres, fecha, lugares, horarios, mapas, textos, música e itinerario.

## 2. Fotos
Coloca tus fotografías dentro de la carpeta `fotos/` y usa estos nombres:

- portada.jpg
- historia1.jpg
- galeria1.jpg
- galeria2.jpg
- galeria3.jpg
- galeria4.jpg
- final.jpg

Si tus archivos tienen otros nombres, cambia los nombres en la sección `FOTOS` de `script.js`.

## 3. Música
Coloca tu archivo MP3 dentro de `musica/` y cambia:

`musica: "musica/nuestra-cancion.mp3"`

por el nombre real del archivo.

## 4. Probarla
Haz doble clic en `index.html` para abrirla en el navegador.

## 5. Próximo paso
Cuando esta versión nos guste, la subiremos a GitHub y luego a Cloudflare Pages para obtener un enlace público.

No hace falta saber programación: iremos paso a paso.
